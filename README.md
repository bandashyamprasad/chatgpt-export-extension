# ChatGPT Export Extension

A **Tampermonkey userscript** to export your ChatGPT conversations into Word or Notepad files. This extension adds a convenient **hover button** to download the conversation directly, supporting both ChatGPT and internal Amazon AI tools.

---

## Features

- Export ChatGPT conversation as `.txt` or `.docx`.
- Hover button appears next to the chat for quick export.
- Supports multi-line and long conversations.
- Works with ChatGPT web and internal Amazon AI tools.

---

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Click **Create a new script**.
3. Copy the code from `exportExtension.user.js` into Tampermonkey.
4. Save the script and reload ChatGPT.
5. You should see the **hover export button** in the chat interface.

---

## Usage

- Open a conversation in ChatGPT.
- Hover over the chat area to see the export button.
- Click **Export** to download the conversation as `.txt` or `.docx`.
